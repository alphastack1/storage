1. Install the read-only bridge

Use Tampermonkey in a supported browser, with Allow User Scripts enabled and access to awbw.amarriner.com. Install this script or copy its contents into Create a new script.

Install / download bridge

Your friend needs this bridge to connect their own AWBW session. They do not need the asset collector.

2. Open your actual game on AWBW

Reload the game tab. Open Field Command · Read-only bridge at the bottom-left, choose Open handheld view, and enter this site’s URL. Keep the original tab open. Field Command mirrors the official terrain canvas, fog, and visible map sprites; it does not submit orders.

3. Help verify the backend adapter

The bridge observes HTTP requests and native WebSocket sends/receives, including paths, field names, and JSON response types while you use the original AWBW interface. It includes whitelisted game/action sample values such as coordinates and unit IDs, while excluding authentication values, arbitrary text, cookies, headers, HTML, and inline scripts. Export inspection downloads this metadata, a rendered map snapshot, and publicly accessible JavaScript/CSS source files retrieved without credentials.

Send the inspection file to the developer. If sprite detection fails, the export still includes diagnostics and public source so the adapter can be corrected. You may also Export snapshot and load it from the battlefield’s Menu.

Current limits

The live map is a read-only rendering of AWBW’s visible DOM, not verified game-state API data. Grey tiles indicate missing coverage. Combat, fog semantics, ownership, HP, and turn permissions are not inferred. Issue real orders in the original AWBW page until those contracts are verified.

Cross-tab connections require a browser that keeps the opener relationship and the AWBW tab active. If your browser blocks that connection, use a snapshot export. Mobile browser and extension support varies; the practice match needs no extension.
